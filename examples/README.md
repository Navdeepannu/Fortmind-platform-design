# Portable UI component examples

These are **illustrative, typed React + Tailwind components**, not a compiled app, not a released library, and **not drop-in replacements** for the live platform. They use semantic Tailwind class names consistent with common shadcn/ui token conventions.

Before integrating, the developer or coding agent must map imports, existing tokens, icon conventions, data types, API responses, action/route semantics and tests from the **real application repository**.
